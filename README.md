# 🎯 Number Guessing Game

_A Java-based application where users have 5 attempts to guess a randomly chosen number between 1 and 100._

---

## 📌 Overview

The **Number Guessing Game** challenges players to guess a randomly selected number within a specified range. Players receive feedback on each guess and have a limited number of attempts to identify the correct number.

**Key Features:**
- 🔢 Random number generation between 1 and 100
- 🎮 5 attempts to guess the correct number
- 📈 Feedback on each guess to guide the player
- 🏆 Win condition upon correct guess within allotted attempts

---

## 🛠️ Tech Stack

- **Programming Language:** Java ☕️

---

## 🎮 How to Play

1. **Start the Game:** Run the application to begin.
2. **Input Guess:** Enter a number between 1 and 100.
3. **Receive Feedback:** The game will inform you if your guess is too high, too low, or correct.
4. **Attempts:** You have a total of 5 attempts to guess the correct number.
5. **Win/Lose:** Guess the number within 5 attempts to win; otherwise, the game reveals the correct number after 5 incorrect guesses.

## 📂 Installation & Usage

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/chirag1689/Number_Guessing_Game.git
cd Number_Guessing_Game
```

### 2️⃣ Compile the Java Program

```bash
javac NumberGuess.java
```

### 3️⃣ Run the Game

```bash
java NumberGuess
```

_(Ensure you have the Java Development Kit (JDK) installed on your system.)_
